# Оверлей звуковой панели (Windows)

Небольшое приложение-оверлей в правом верхнем углу экрана для проигрывания аудио и отображения того, что играет в системе (например, Yandex Music).

Файлы:
- `overlay.py` — основной скрипт с интерфейсом оверлея и наблюдателем за системными медиа.
- `requirements.txt` — зависимости.

Установка и запуск:

1. Создайте виртуальное окружение (рекомендуется):

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

2. Установите зависимости:

```powershell
pip install -r requirements.txt
```

3. Запустите оверлей:

```powershell
python overlay.py
```

Примечания:
- Оверлей пытается использовать системный Windows SMTC для определения текущего трека и управления воспроизведением. Пакет `winrt` теперь включён в `requirements.txt` для поддержки этой опции на Windows.
- Если вы используете Yandex Music в браузере, браузер должен передавать медиасессию в систему (обычно поддерживается). Если SMTC не доступен, приложение пытается читать заголовок окна браузера/плеера.
